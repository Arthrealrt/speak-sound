# v0.10 按键与侧栏复核

延续 design-taste-frontend 的 True-black flat 方向，seed 1992423212，未重新抽取。用户明确要求侧栏透明，因此以用户指令覆盖技能关于不使用透明表面的默认约束；没有增加模糊、渐变或装饰性动效。

- 首页把「按住说话」和「修改按键」放在一行，当前键可直接辨认；对话框呈现真实输入，支持保存、取消和恢复 F8。运行时锁定该设置，松键后才允许开始发送。
- 导航静止时底透明；150 ms OutCubic 只用于悬停反馈，文字右移 4 px。动画从当前值反向，快速移动不会跳回起点。选中状态使用固定标记，焦点边框独立显示。
- 侧栏底 RGBA(12,14,17,190)，主工作区保持黑色。提高侧栏次要文字亮度，以保持浅色桌面下的可读性。透明不是整窗淡化，控件、字幕行为和音频链路均保留。
- Windows 局部透明采用 Qt 官方要求的 FramelessWindowHint 与 WA_TranslucentBackground；参考 [Qt QWidget 文档](https://doc.qt.io/qt-6/qwidget.html#creating-translucent-windows)。提供标题栏拖动、双击及窗口按钮，边缘通过原生 WM_NCHITTEST 缩放。

复核：三种尺寸、七个页面均原生渲染；查看首页的宽/窄窗口、透明合成、悬停状态与按键对话框。没有浏览器 DOM 检查声明。97 项测试和本机 Windows 合成/缩放/悬停/最大化验证通过；小窗口滚动为预期行为。静态主题 lint 用相同内容的 CSS 镜像运行，只验证样式规则，不代表原生窗口几何检查。
